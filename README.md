# Enthropy

Креатор персонажей в духе Picrew: два формата (в полный рост / лицо), два стиля рисовки (чистый лайн / скетч),
сохранение персонажей в браузере, экспорт PNG/SVG/JSON. Мудборды — следующий этап.

```bash
npm install
npm run dev
```

Детали рисуются векторно (`src/parts/*`), реестр категорий — `src/parts/registry.ts`, порядок слоёв — `src/parts/types.ts`.
