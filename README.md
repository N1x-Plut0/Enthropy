# Enthropy

Креатор персонажей в духе Picrew по рефам «character sheet»: два формата (в полный рост / лицо),
слои с выбором деталей и цветов, позы и эмоции, сохранение персонажей в браузере, экспорт PNG/SVG/JSON.
Мудборды — следующий этап.

```bash
npm install
npm run dev
```

- детали рисуются векторно в `src/parts/*`, категории в `src/parts/registry.ts`
- порядок слоёв и пропорции (масштаб головы, растяжка ног) в `src/parts/types.ts`
